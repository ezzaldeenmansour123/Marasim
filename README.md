# مراسم | MARASIM

**منصة البروتوكول الدولي والمراسم والذكاء الاصطناعي**

تطبيق أندرويد حقيقي (Flutter) — دليل بروتوكول موثوق بمصادره، وموسوعة دول،
ومساعد ذكي يعمل دون إنترنت، وأدوات تنفيذية لتنظيم المناسبات والزيارات الرسمية.

- **الحزمة:** `com.marasim.app.marasim` — **الإصدار:** 1.0.1+2
- **المؤسس والمطوّر:** عز الدين منصور — Ezzaldeen Mansour
  (تظهر بياناته في صفحة «عن مراسم» فقط، وليس في الشاشة الرئيسية)
- **اللغة:** عربية أولًا (RTL) مع تبديل واجهة إنجليزي/عربي **كامل**
  لكل عناصر الواجهة (تُقلب الاتجاه إلى LTR عند الإنجليزية)؛ محتوى
  المقالات والدول عربي مع الأسماء الإنجليزية (ترجمة المحتوى نفسه
  جهد منفصل، انظر «مؤجَّل»).

## ما الجديد في 1.0.1 (إصلاحات بناءً على اختبار المستخدم للنسخة 1.0.0)

- **المساعد الذكي يعمل فعلًا:** كان يرد «لا توجد معلومة موثوقة» على
  الأسئلة الطبيعية لأن البحث كان يطابق **كل** كلمة بما فيها كلمات
  السؤال (كيف/ما/تتم) ولا يطابق الجمع (وفد ≠ وفود). أُصلح البحث:
  حذف كلمات الاستفهام/الطلب، وربط المفرد بالجمع، ثم استراتيجية
  احتياطية (AND ثم OR ثم أطول كلمة) مع حماية try/catch حتى لا يعلق
  المؤشر أبدًا. **مُتحقق بالمحاكاة على قاعدة البيانات الحقيقية:**
  الأزرار السبعة السريعة والأسئلة السبعة النموذجية تعيد ≥1 نتيجة
  لكل منها، وأول نتيجة صحيحة في كل الحالات.
- **الوضع الليلي:** سمة داكنة كاملة (خلفية #0A1826، بطاقات #162E47،
  نص أبيض لؤلؤي، ذهبي للتأكيدات) + مفتاح محفوظ في الإعدادات وتبديل
  سريع في صفحة «المزيد». كل الشاشات (بطاقات، حقول، حوارات، شريط
  التنقل) مقروءة في الوضعين.
- **الترجمة فعّالة:** خريطة نصوص موسّعة تغطي كل عناصر الواجهة
  (الرئيسية، البحث، المساعد، الموسوعة، الدليل، المكتبة، الأدوات،
  الإعدادات، الحوارات، الحالات الفارغة) عبر `tr()`/`trc()`.
- **الخطوط:** خط Cairo الحديث النظيف لواجهة الاستخدام، وخط Amiri
  للعناوين العرضية فقط (شاشة البداية، عناوين المقالات، رؤوس الأقسام).
  يُشتق Cairo من خطه المتغير عبر fonttools في CI (أوزان حقيقية
  400/700)، وملفات TTF ملتزمة في `assets/fonts/` كاحتياطي.
- **خلفية متحركة:** الرئيسية وشاشة البداية بخلفية صور معبّرة
  تتلاشى كل 6 ثوانٍ مع تقريب سينمائي بطيء (Ken Burns) خلف طبقة
  كحلية داكنة تحافظ على قراءة المحتوى؛ الصور محمّلة مسبقًا (precache).
- **دليل البروتوكول:** توسّع من 34 إلى **49 مقالًا** — كل قسم من
  الأقسام الـ16 فيه 3 مقالات على الأقل (العلاقات الدبلوماسية 4)،
  وحالات فارغة مع زر إعادة محاولة بدل القوائم الفارغة.
- **حقول الإدخال:** تدقيق شامل لكل الحقول والأزرار في الأدوات
  والمكتبة والإشعارات وتصدير PDF (قيم فارغة، قوائم منسدلة، منتقي
  التاريخ، حفظ الحالة، تداخل لوحة المفاتيح، أزرار بلا أثر).
  **إصلاح إضافي:** كان حفظ مخطط الجلوس يفقد فئة منصب كل ضيف (يعيد
  تحميلهم كلهم «سفير») — أُضيف عمود `rank_category` إلى جدول
  `seating_assignments` مع ترحيل تلقائي (ALTER TABLE) لتثبيتات 1.0.0
  الحالية، فتُحفظ الفئة وتُستعاد وتُستخدم في الترتيب التلقائي.
  الترجمة غطّت أيضًا كل نصوص الأدوات (العناوين، التسميات، الحوارات،
  رسائل الخطأ، نتائج مدقق البروتوكول) بما فيها تسميات الفئات
  (سفير/وزير/...) والقيم المخزنة (شكل المائدة، نوع المناسبة) مع
  بقاء قيم البيانات نفسها عربية في قاعدة البيانات.

## المزايا (كلها تعمل — لا أزرار وهمية)

- **الشاشة الرئيسية:** خلفية صور متحركة، بحث عام (مقالات + دول +
  نماذج)، 6 بلاطات، أحدث المقالات، الأعياد الوطنية القادمة (30 يومًا).
- **المساعد الذكي (MARASIM AI):** بحث استرجاعي فقط في قاعدة المعرفة (FTS5،
  حتى 6 نتائج) — يجيب بالقاعدة + المصدر + تاريخ المراجعة، ويقول صراحة
  «لا توجد معلومة موثوقة» عند غيابها. لا يخترع قواعد أو ألقابًا أو تراتيب.
  أسئلة سريعة جاهزة، وصياغة مسودات من النماذج، ومراجعة خطة مناسبة.
  يعمل دون إنترنت بالكامل.
- **موسوعة الدول:** 30 دولة — بحث + صفحة تفصيل لكل دولة (عاصمة، لغات،
  عملة، مناطق زمنية، نظام الحكم، العيد الوطني، ملاحظة بروتوكولية،
  ملاحظة ألقاب، مصادر).
- **دليل البروتوكول:** 49 مقالًا موثقًا في 16 قسمًا (3 مقالات على الأقل
  في كل قسم)، مع نوع القاعدة (ملزمة دوليًا / ممارسة شائعة).
- **حاسبة الأسبقية:** إضافة أشخاص (الاسم، الفئة، الدولة، تاريخ تولي
  المهام) → ترتيب مطبق عليه قاعدة اتفاقية فيينا (المادتان 13 و16) + شرح.
- **مخطط الجلوس:** مستديرة / مستطيلة / U — ترتيب تلقائي حسب الأسبقية +
  إعادة ترتيب يدوية + حفظ/تحميل في SQLite.
- **منظم المناسبات:** إنشاء مناسبة (النوع، التاريخ، المكان، الضيوف)،
  قائمة ضيوف، فقرات برنامج، قائمة تحقق مولّدة تلقائيًا + عناصر مخصصة،
  تذكير محلي صباح يوم المناسبة.
- **مولّد المستندات:** تعبئة دعوة رسمية / مذكرة شفوية / برنامج زيارة /
  جدول أعمال / قائمة ضيوف / قائمة تحقق / افتتاحية كلمة → معاينة →
  تصدير PDF (خط أميري، RTL) + مشاركة.
- **فاحص البروتوكول:** اختيار مناسبة محفوظة → فحوصات قاعدية (ترتيب
  الأعلام، ترتيب الجلوس، فقرات ناقصة، ألقاب، تعارض مع عيد وطني) →
  قائمة مشكلات، كل منها بالقاعدة + المصدر + التوصية.
- **المكتبة:** روابط حقيقية لوثائق عامة (اتفاقية فيينا للعلاقات
  الدبلوماسية 1961، اتفاقية فيينا للعلاقات القنصلية 1963، ميثاق الأمم
  المتحدة، دليل بروتوكول الأمم المتحدة) + النماذج الجاهزة.
- **الإشعارات:** تذكير بالأعياد الوطنية + تذكير بالمناسبات (قابلة
  للإيقاف من الإعدادات).
- **المفضلة** (مقالات + دول)، **الإعدادات** (لغة، حجم الخط، **وضع ليلي**،
  إشعارات، حقل اختياري لمفتاح API لوضع توليدي مستقبلي — يُحفظ على
  الجهاز فقط، والتطبيق يعمل كاملًا بدونه).

## مصادر المعرفة (حقيقية وموثقة)

- اتفاقية فيينا للعلاقات الدبلوماسية 1961 — المواد 13 و16 (الأسبقية)،
  14 (فئات رؤساء البعثات)، 22 (حرمة مقر البعثة)، 29 (حرمة المبعوث)،
  41 (احترام قوانين الدولة المضيفة). مصدرها: الأمم المتحدة
  (legal.un.org / treaties.un.org).
- اتفاقية فيينا للعلاقات القنصلية 1963 — الأمم المتحدة.
- ميثاق الأمم المتحدة — مبدأ المساواة السيادية.
- ما عدا ذلك: «ممارسة شائعة» موثقة كذلك، وليست منسوبة إلى معاهدة.
- كل سجل في قاعدة البيانات يحمل `source_name` و`source_org` و`source_url`
  وتاريخ مراجعة `2026-11-24`.

## بنية المشروع

```
lib/main.dart          # التطبيق: شاشة البداية، الرئيسية (خلفية متحركة)، البحث، الإعدادات، حول
lib/app_state.dart     # حالة عامة (لغة، خط، إشعارات، وضع ليلي، API) + خريطة ترجمة الواجهة
lib/db.dart            # Repo + SQLite + FTS5 (بحث عربي: كلمات توقف + مفرد/جمع + AND→OR→أطول كلمة)
lib/assistant.dart     # المساعد الاسترجاعي + صياغة المسودات
lib/encyclopedia.dart  # موسوعة الدول + دليل البروتوكول + قارئ المقالات
lib/tools.dart         # الأدوات: الأسبقية، الجلوس، المناسبات، المستندات، الفاحص
lib/library.dart       # المكتبة (روابط الوثائق + النماذج)
lib/widgets.dart       # الألوان، السمتان (فاتحة/ليلية)، الخلفية المتحركة، البطاقات
lib/notifications.dart # الإشعارات المحلية (flutter_local_notifications 22.3.3)
lib/pdf_export.dart    # تصدير PDF بخط أميري واتجاه RTL
tools/build_db.py      # بناء assets/marasim.db من tools/seed/*.json
tools/make_icon.py     # توليد أيقونة التشغيل من assets/logo.png (PIL)
tools/seed/            # البيانات المنسقة: articles.json (49)، countries.json (30)، templates.json (7)
assets/logo.png        # شعار مراسم (غلوب ذهبي على عمود مع غار)
assets/fonts/          # Cairo (واجهة) + Amiri (عناوين) — ملفات TTF ملتزمة كاحتياطي
.github/workflows/build.yml  # بناء APK عبر GitHub Actions + نشر Release
```

## البناء (GitHub Actions — الطريقة المعتمدة)

البناء المحلي بـ Gradle غير ممكن في بيئة التطوير الحالية (Java loopback
محظور) — لذلك يُبنى التطبيق عبر GitHub Actions:

1. أنشئ مستودعًا عامًا باسم `Marasim` على GitHub.
2. ارفع ملفات هذا المشروع عبر موقع GitHub (Upload files) — ارفع مجلد
   `.github/workflows/` **أخيرًا** حتى لا يبدأ البناء قبل اكتمال الرفع.
3. بعد اكتمال الرفع يبدأ البناء تلقائيًا (أو من تبويب Actions →
   Run workflow). مدته المتوقعة 7–8 دقائق.
4. عند النجاح: يُنشأ Release بالوسم `build-<رقم التشغيل>` وفيه ملف
   `Marasim.apk` — حمّله وثبّته على الهاتف.

**نقاط حرجة في البناء (مثبتة من مشاريع سابقة):**

- `flutter_local_notifications` مثبت على `^22.3.3` — **لا ترفّعه إلى 23.x**؛
  فالإصدار 23 يتطلب compileSdk 37، ومنصة android-37 غير موجودة في
  مستودعات عدّاء Actions ولا يمكن تثبيتها.
- `compileSdk` يبقى على الافتراضي (36)؛ وملف البناء يفعّل
  `isCoreLibraryDesugaringEnabled` + `desugar_jdk_libs 2.1.5`.
- سطر pip في خطوة صور الواجهة يتضمن `pillow` (يحتاجه `make_icon.py`).
- صور الواجهة (8 صور Unsplash) تُحمَّل في CI؛ عند فشل أي تحميل يُولَّد
  بديل كحلي/ذهبي بـ PIL تحت الاسم نفسه حتى لا يتعطل البناء أبدًا.

## مؤجَّل (ليس في v1.0.1)

- **تصدير DOCX** — التصدير PDF فقط.
- **الوضع التوليدي للمساعد (LLM)** — يحتاج مفتاح API وخادمًا؛ الحقل موجود
  في الإعدادات، والمساعد الاسترجاعي يعمل كاملًا بدونه.
- **بناء iOS** — يحتاج حساب Apple Developer (99$/سنة) + شهادات توقيع
  من مالك الحساب؛ لا يمكن إنجازه من بيئة البناء الحالية وحدها.
- **ترجمة محتوى المقالات والدول إلى الإنجليزية** — الواجهة مترجمة بالكامل،
  أما نصوص المعرفة فتبقى عربية (مع الأسماء الإنجليزية للدول) حتى
  تُراجَع ترجمتها مصدرًا بمصدر.
- **محدوديتان معروفتان في مخطط الجلوس:** إعادة حفظ مخطط معدَّل تتم
  بحذف الصف القديم وإعادة إدخاله (معرّف جديد؛ آمن لأنه لا شيء آخر
  يشير إلى معرّفات المخططات) بدل تحديث مباشر — دالة `updatePlan`
  مخصصة ستكون أنظف. وضيوف الجلوس بلا تاريخ تقديم أوراق اعتماد،
  فيُرتَّب السفراء في المخطط بالاسم فقط لا بالتاريخ.
- محتوى الإعجاز/القراءات الصوتية ليس جزءًا من هذا التطبيق (خاص بتطبيق تلاوة).
